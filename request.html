要望の送り方

GitHub Discussions で、掲載内容の訂正・追加・削除のご要望を受け付けています

このサイトへのご要望は、GitHub（ギットハブ）というサービスの「Discussions（ディスカッション）」という掲示板で受け付けています。 GitHub は無料で使えます。アカウントを作ったことがない方でも、このページの手順どおりに進めれば、10分ほどで投稿できます。

流れ

  1. GitHub のアカウントを作る（すでに持っている方は飛ばしてOK）
  2. メールアドレスを守る設定をする（任意・気になる方だけ）
  3. Discussions に要望を投稿する

GitHub の画面は英語です。このページでは、押すボタンを Sign up のように表示しています。画面のデザインは変わることがあるので、多少違っていても近い名前のボタンを探してみてください。

GitHub のアカウントを作る

  1. GitHub の登録ページを開きます。
  2. 登録の方法を選びます。
    • Google アカウントで登録する：Continue with Google を押します。
    • メールアドレスで登録する：メールアドレス、パスワード、ユーザー名を入力します。
  3. ユーザー名（Username）を決めます。ユーザー名は投稿に表示され、誰でも見られます。 本名や、ほかの SNS と同じ名前を出したくない方は、別の名前にしておくと安心です。使えるのは英数字とハイフン（-）です。
  4. ロボットではないことの確認（簡単なパズルなど）が出たら、画面の案内に沿って答えます。
  5. 登録したメールアドレスに、GitHub から確認コードが届きます。届いたコードを画面に入力します。 届かないときは、迷惑メールのフォルダも見てみてください。
  6. 使い方などの質問画面が出たら、答えても、Skip などで飛ばしても大丈夫です。

「This email can't be used」などのエラーが出たときは、別のブラウザで試す、少し時間をおいて試す、別のメールアドレスを使う、といった方法があります。 詳しくは GitHub 公式のアカウント作成の解説をご覧ください。 また、登録後に「2要素認証（2FA）」の設定を勧められます。アカウントを乗っ取られにくくなるので、設定しておくのがおすすめです。

メールアドレスを公開したくない方へ

まず安心してほしいのは、登録したメールアドレスは、初期設定のままでは他の人に表示されないということです。 Discussions に投稿しても、表示されるのはユーザー名とアイコンだけです。

さらに念のため、次の設定をしておくとより安心です。

  1. ログインした状態で、メールアドレスの設定ページを開きます （右上のアイコン → Settings → 左のメニューの Emails でも開けます）。
  2. Keep my email addresses private にチェックを入れます。 同じページの Block command line pushes that expose my email にもチェックを入れておくと、なお安心です。
  3. 左のメニューの Public profile を開き、Public email が Don't show my email address（表示しない）になっていることを確認します。

2番の設定は、主にプログラムを書く人向けのもので、オンにしておくとメールアドレスの代わりに GitHub 専用の匿名のアドレスが使われます。 詳しくは GitHub 公式のメールアドレスの設定の解説をご覧ください。

それでも普段のメールアドレスを使うのが気になる方は、GitHub 用に新しいメールアドレス（Gmail などの無料のもの）を作って、それで登録する方法もあります。

Discussions に要望を投稿する

  1. このサイトの Discussions を開きます。ログインしていなければ、ログインします。
  2. 右上の New discussion を押します。
  3. カテゴリ（投稿の種類）を選びます。迷ったら Ideas で大丈夫です。
    こんなとき選ぶカテゴリ
    内容の訂正・追加・削除をお願いしたいIdeas
    サイトについて質問したいQ&A
    それ以外（感想など）General
    Announcements は運営からのお知らせ用なので、投稿できません。
  4. タイトル（Title）と本文を書いて、Start discussion を押せば投稿完了です。

訂正・追加・削除の要望を書く（Ideas）

書き方の例

タイトル：【訂正】活動歴 9/19 の内容

本文：

  • どこを：活動歴の 2026-09-19 の行
  • どう直してほしいか：〇〇を△△に直してほしいです
  • 出典：https://www.youtube.com/watch?v=…（〇分ごろ）

このサイトは、公式の配信や X のポストを出典にしています。出典の URL（配信なら話していた時間も）を書いてもらえると、確認して反映しやすくなります。

投稿するときのお願い

  • Discussions は誰でも見られる場所です。本名・住所・連絡先などの個人情報は書かないでください。
  • 配信やポストで公開されていない情報や、九日なここさんのご迷惑になりそうな話題は扱いません。
  • ご本人さま・関係者さまからの訂正や削除のご要望は、優先して対応します。
  • 個人で運営しているため、お返事や反映に時間がかかることがあります。

投稿したあと

  • 返信がつくと、GitHub から登録したメールアドレスにお知らせが届きます。
  • 自分の投稿は、投稿の右上の … から、あとで編集や削除ができます。

Discussions の使い方は、GitHub 公式のディスカッションへの参加の解説にもまとまっています。
